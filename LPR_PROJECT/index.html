A low numerical slope error does not prove calibration, reference integrity, timely acquisition or recovery. Accordingly, “withheld error ≤5%” is not automatically an incorrect rejection.

What was added

  • Fresh Elmer conductivity and mesh verification with a hash-bound simulation Ru interface.
  • Independent switched-standard training, holdout and positive reference measurements at both ends.
  • Existing P3 correction API supplied only with qualified simulation Ru and declared uncertainty.
  • Decision-driven native reference verification and 45-second reacquisition, with exact prefix equivalence checks.
  • Native fault matrix and three ungated baseline estimators evaluated on identical data.

Limits that remain visible

The 3D specimen's flux/mesh qualification is unresolved. The simulated reference uses an ideal nonloading point. Geometry and conductivity uncertainty are assumed distributions, not measured tolerances. P3's settling and heuristic uncertainty limitations remain. This pilot uses one noise seed per case. No physical instrument, physical calibration or material corrosion-rate validation occurred.
